# Zombies With Pickaxes (Forge 1.20.1)

No wall is safe! Zombies spawn carrying pickaxes, actively breaking blocks, digging through player fortifications, and building bridges with collected materials.

---

## 🌟 Features

* **Obstacle Mining**: Zombies detect blocks obstructing their path to a player and mine through them using realistic tool breaking times and block crack animations.
* **Scaffolding & Bridging**: Collects mined blocks to place steps and bridge across gaps to reach elevated players.
* **Tiered Tools**: Can spawn with Wooden, Stone, Iron, Golden, or Diamond pickaxes with corresponding mining speeds.
